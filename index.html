Hubungkan Cloud Pribadi

Sinkronkan data ke Firebase gratis Anda

Agar data tersimpan di Cloud saat diakses lewat GitHub Pages, tempelkan konfigurasi Firebase SDK (JSON) dari console.firebase.google.com di bawah ini:

Petunjuk Cepat:

1. Buka console.firebase.google.com → Buat Proyek Gratis.

2. Aktifkan Build → Authentication → Anonymous.

3. Aktifkan Build → Firestore Database (Mode Uji / Test Mode).

4. Buka Project Settings → Tambah Web App (</>) → Salin isi firebaseConfig ke kotak di atas.
